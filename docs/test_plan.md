# HR Recruitment Automation System – Requirements

## 1. Functional Requirements

1. Upload candidate datasets in CSV and Excel formats.
2. Validate candidate information.
3. Identify missing fields, invalid email addresses and duplicate records.
4. Extract candidate information from PDF resumes.
5. Allow HR to specify required skills.
6. Apply exact experience matching.
7. Evaluate education qualifications.
8. Check maximum notice period.
9. Calculate weighted candidate match scores.
10. Display screening recommendations.
11. Maintain HR review status.
12. Generate final screening reports in CSV and Excel formats.

## 2. Non-Functional Requirements

- User-friendly interface.
- Reliable data processing.
- Secure handling of candidate information.
- Modular and maintainable code.
- Input validation and error handling.
- Clear reporting and logging.

## 3. Technologies

- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Data Processing: Pandas
- Database: SQLite
- Deployment: Netlify and Render
- Version Control: GitHub

## 4. Input Requirements

- Candidate CSV files
- Candidate Excel files
- PDF resumes

## 5. Output Requirements

- Valid candidate records
- Invalid candidate records
- Screening results
- CSV reports
- Excel reports
- HR review information
